# Butter Story — Bakery & Cafe, Lucknow

One-page website for Butter Story, a pure vegetarian bakery and cafe chain in Lucknow.

## About

Butter Story is a bakery and cafe chain in Lucknow serving handcrafted vegetarian bakes and cafe items. This repository holds the single-page website built for the business in October 2026.

## What is inside

- `index.html` — the complete one-page website (hero, about, menu highlights and visit info)
- Pure static HTML/CSS/JS, no build step, no backend

## Notes

- Site copy is in professional English.
- This is a maintenance-only repository: small updates and fixes only, no new project builds.
